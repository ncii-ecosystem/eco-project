A public () and living () database gathering sources across academia, industry, civil society, and journalism that document, investigate, and analyze the ecosystem of technologies facilitating AI-generated non-consensual intimate images (AIG-NCII).

How to Use This Database

  • Search for a topic, author, or source, and filter results by technology or source type. Sort by date or title, and open an entry to read its original source.
  • Choosing several technologies matches entries related to any of them. Technology, type, and search filters work together.
  • Export your current results as a CSV file for further analysis. CSV files contain the metadata fields “title”, “authors”, “link”, “Date”, “provenance”, and “technologies”.
  • Submit a new source through “Submit Entries” to help grow the collection. You can contribute anonymously or choose to be credited.

Methodology

We group sources using the framework from Ding et al. (2026): creation, distribution, proliferation and discovery, infrastructural support, and monetization. A source can cover more than one technology.

The database brings together papers, articles, reports, and other sources we’ve collected so far. It doesn’t cover everything, and several entries may discuss the same event. Counts show how many sources we’ve collected, not how often harm occurs or which technologies matter most.

Want to Contribute a Source?

Our database is a living resource. Anyone who wants to contribute a source can fill out the submission form. You can submit both your own work or someone else’s work. All contributors will be acknowledged with their consent. Researchers review each submission before it appears here, so your entry won’t be visible right away. We check that the source is relevant, the details are accurate, and it isn’t already listed. Submissions that meet these criteria are added to the collection.

Spot an Error?

We tried our best to accurately provide meta data for each entry. However, if you spotted an error in your work, want to update any fields, or want to be removed from the database, please email michelle_ding@brown.edu.
