# ncii-ecosystem 🧩

## Frontend

```bash
npm run site
```

Open [http://localhost:8000](http://localhost:8000)

## Backend (Sanity Studio)

```bash
npm install --prefix studio
npm run studio
```

Open [http://localhost:3333](http://localhost:3333)

The story loads fonts, icons and scrollama from the internet, so it needs an internet connection.
